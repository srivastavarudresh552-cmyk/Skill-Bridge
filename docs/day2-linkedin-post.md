Day 2 of building SkillBridge 🚀

SkillBridge is an AI-powered app that tells job seekers exactly which skills to prioritize for a target role — using resume + job description input and Claude to generate a personalized, trackable learning roadmap.

Today was all about turning yesterday's plan into a real technical blueprint before writing a single line of production code:

→ Set up the GitHub repo and initial MERN project structure
→ Finalized the stack: React + Vite + Tailwind, Express + MongoDB Atlas, JWT auth, and the Anthropic Claude API for the AI analysis
→ Designed the full system architecture (component diagram, data flow, request lifecycle)
→ Designed the database schema and validated it against every user story
→ Mapped out all v1.0 API endpoints
→ Sketched the complete user flow and low-fidelity wireframes
→ Documented the project structure so tomorrow can go straight into implementation

Building this as a 10-day capstone for the AB Talks 60-Day Claude AI Challenge — full SDLC, from requirements to deployment. Day 3 starts implementation.
